# Database Schema - Explore Ormawa Undiksha

## 1. Informasi Database

- Backend: Supabase
- Database: PostgreSQL
- Tabel katalog organisasi: `ormawa`
- Tabel daftar organisasi tersimpan: `saved_ormawa`

Dokumentasi ini menjelaskan struktur kolom yang digunakan oleh aplikasi Flutter berdasarkan `SavedOrmawaModel` dan `SavedOrmawaDbService`.

Tipe data SQL berikut merupakan rancangan yang sesuai dengan kebutuhan model aplikasi. Cocokkan kembali dengan struktur tabel aktual di Supabase sebelum menjalankan SQL.

## 2. Struktur Tabel saved_ormawa

| Kolom | Tipe Data yang Disarankan | Keterangan |
|---|---|---|
| id | BIGINT | Identitas unik data, primary key |
| student_nim | TEXT | NIM mahasiswa pemilik data |
| ormawa_id | BIGINT | ID organisasi dari katalog |
| ormawa_name | TEXT | Nama organisasi |
| category | TEXT | Kategori organisasi |
| target_division | TEXT | Divisi yang diminati |
| note | TEXT | Catatan atau motivasi mahasiswa |
| priority | INTEGER | Tingkat prioritas, skala 1-5 |
| created_at | TIMESTAMPTZ | Waktu pembuatan data |

## 3. Rancangan SQL

Berikut contoh rancangan pembuatan tabel PostgreSQL yang sesuai dengan kebutuhan aplikasi. Gunakan hanya jika tabel belum tersedia dan setelah menyesuaikan tipe `ormawa_id` dengan tabel katalog.

```sql
CREATE TABLE IF NOT EXISTS public.saved_ormawa (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    student_nim TEXT NOT NULL,
    ormawa_id BIGINT NOT NULL,
    ormawa_name TEXT NOT NULL,
    category TEXT NOT NULL,
    target_division TEXT NOT NULL,
    note TEXT DEFAULT '',
    priority INTEGER NOT NULL DEFAULT 3
        CHECK (priority BETWEEN 1 AND 5),
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);
```

Catatan: Rancangan ini bukan instruksi untuk menimpa tabel yang sudah digunakan. Periksa skema aktual dan kebijakan database sebelum melakukan perubahan.

## 4. Operasi CRUD

Aplikasi mengakses tabel `saved_ormawa` melalui `SavedOrmawaDbService`.

| Operasi | Metode | Keterangan |
|---|---|---|
| Create | INSERT | Menambahkan organisasi ke daftar minat |
| Read | SELECT | Mengambil data berdasarkan `student_nim` |
| Update | UPDATE | Memperbarui divisi, catatan, dan prioritas berdasarkan `id` |
| Delete | DELETE | Menghapus data berdasarkan `id` |

Data yang ditampilkan diurutkan berdasarkan:
1. `priority` secara menurun.
2. `created_at` secara menurun.

## 5. Integrasi dengan Flutter

Model data berada pada:

`lib/models/saved_ormawa_model.dart`

Service database berada pada:

`lib/services/saved_ormawa_db_service.dart`

Model menyediakan beberapa fungsi:
- `fromJson()` untuk mengubah data JSON menjadi objek Dart.
- `toInsertJson()` untuk menyiapkan data penambahan.
- `toUpdateJson()` untuk menyiapkan data pembaruan.

## 6. Keamanan Database

- Gunakan Supabase anon key atau publishable key pada konfigurasi aplikasi.
- Jangan memasukkan `service_role` key ke aplikasi Flutter.
- Aktifkan Row Level Security (RLS) dan sesuaikan kebijakan akses dengan mekanisme identitas mahasiswa yang digunakan aplikasi.
- Jangan menganggap filter `student_nim` dari aplikasi sebagai pengganti kebijakan keamanan database.
- Uji operasi CRUD dan pembatasan akses sebelum aplikasi digunakan secara luas.
